# Review and Improvements

The migration consolidates ten reviewer lanes into one `reviewer` agent while
retaining a focus catalog. This preserves specialized checklists without
duplicating prompts or model configuration. Fresh invocation correlation,
packet evidence, health-first coverage, and strict finding validation remain
part of the contract.

The `simplify` focus is an ordinary selected focus; it is not a second phase
and never depends on results from another focus.
